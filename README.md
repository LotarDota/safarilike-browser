# Botva AutoClicker

Автокликер для браузерной игры [Botva.ru](https://botva.ru/) — автоматизирует рутинные действия: атаку, лечение, ферму, дозор и шахту.

**Два варианта использования:**
- **Отдельная программа** (Python + Selenium) — скачал, запустил, играешь
- **Userscript** (Tampermonkey) — встраивается прямо в браузер

## Возможности

| Модуль        | Описание                                                              |
|---------------|-----------------------------------------------------------------------|
| Авто-Атака    | Поиск противника по диапазону уровней и автоматическое нападение      |
| Авто-Лечение  | Использование зелий при падении HP ниже заданного порога              |
| Авто-Ферма    | Автоматический сбор ресурсов на ферме                                |
| Авто-Дозор    | Автоматический поход в дозор                                         |
| Авто-Шахта    | Автоматическая добыча кристаллов                                     |

### Дополнительно

- Графический интерфейс с вкладками
- Настраиваемые интервалы и задержки
- Случайная задержка между действиями (анти-детект)
- Статистика сессии (атаки, победы, поражения и т.д.)
- Журнал действий в реальном времени
- Сохранение настроек между сессиями

## Вариант 1: Отдельная программа (Python)

### Требования

- Python 3.10+
- Google Chrome
- ChromeDriver (устанавливается автоматически через Selenium)

### Установка

```bash
# Клонировать репозиторий
git clone https://github.com/LotarDota/safarilike-browser.git
cd safarilike-browser

# Установить зависимости
pip install -r requirements.txt
```

### Запуск

```bash
python run.py
```

или

```bash
python -m botva_autoclicker
```

### Сборка в EXE (Windows)

Чтобы собрать один `.exe` файл, который можно запускать без установки Python:

```bash
# Установить зависимости (если ещё не установлены)
pip install -r requirements.txt

# Собрать EXE
python build_exe.py
```

Готовый файл: `dist/BotvaAutoClicker.exe`

Просто скопируйте `BotvaAutoClicker.exe` на любой компьютер с Windows и запустите двойным кликом. Python устанавливать **не нужно**. Google Chrome должен быть установлен.

### Как пользоваться

1. Запустите программу (`python run.py`)
2. Откроется окно **Botva AutoClicker**
3. На вкладке **Вход** введите логин, пароль и выберите сервер
4. На вкладке **Модули** включите нужные модули и настройте параметры
5. Нажмите кнопку **ЗАПУСТИТЬ**
6. Программа откроет Chrome, войдёт в игру и начнёт автоматически выполнять действия

#### Скрытый режим (headless)

Поставьте галочку **"Скрытый режим"** на вкладке Вход — браузер будет работать в фоне без окна.

#### Настройки сохраняются

Все настройки автоматически сохраняются в файл `~/.botva_autoclicker.json` и загружаются при следующем запуске.

## Вариант 2: Userscript (Tampermonkey)

### 1. Установите менеджер пользовательских скриптов

| Браузер           | Расширение                                                                 |
|-------------------|---------------------------------------------------------------------------|
| Chrome / Edge     | [Tampermonkey](https://www.tampermonkey.net/)                             |
| Firefox           | [Tampermonkey](https://www.tampermonkey.net/) или [Greasemonkey](https://addons.mozilla.org/ru/firefox/addon/greasemonkey/) |
| Safari            | [Tampermonkey](https://www.tampermonkey.net/)                             |
| Opera             | [Tampermonkey](https://www.tampermonkey.net/)                             |

### 2. Установите скрипт

**Вариант А** — нажмите кнопку ниже (если поддерживается вашим менеджером скриптов):

[Установить botva-autoclicker.user.js](botva-autoclicker.user.js)

**Вариант Б** — вручную:

1. Откройте панель Tampermonkey -> «Создать новый скрипт»
2. Удалите содержимое и вставьте код из файла `botva-autoclicker.user.js`
3. Сохраните скрипт (Ctrl+S)

### 3. Откройте игру

Перейдите на [botva.ru](https://botva.ru/) и войдите в игру — панель автокликера появится в верхнем левом углу.

### Использование Userscript

1. Перейдите на вкладку **Модули** в панели
2. Включите нужные модули переключателями
3. Настройте параметры (диапазон уровней, порог HP и т.д.)
4. Нажмите кнопку **ЗАПУСТИТЬ**

#### Горячие клавиши (только userscript)

| Комбинация       | Действие                     |
|------------------|------------------------------|
| `Ctrl+Shift+B`   | Показать / скрыть панель    |
| `Ctrl+Shift+S`   | Запустить / остановить бота |

## Настройка модулей

### Авто-Атака

| Параметр      | По умолчанию | Описание                                |
|---------------|-------------|-----------------------------------------|
| Ур. от        | 1           | Минимальный уровень противника          |
| Ур. до        | 99          | Максимальный уровень противника         |
| Интервал      | 15 сек      | Время между циклами атаки               |

### Авто-Лечение

| Параметр            | По умолчанию | Описание                          |
|---------------------|-------------|-----------------------------------|
| Лечить при HP ниже  | 30%         | Порог HP для автоматического лечения |
| Интервал            | 10 сек      | Частота проверки HP               |

### Авто-Ферма / Дозор / Шахта

| Параметр  | По умолчанию | Описание                          |
|-----------|-------------|-----------------------------------|
| Интервал  | 60 сек      | Время между циклами               |

## Безопасность

- Программа и скрипт работают исключительно на стороне клиента
- Никакие данные не отправляются на сторонние серверы
- Настройки сохраняются локально
- Случайные задержки между действиями снижают вероятность обнаружения
- Пароль хранится в локальном конфиге `~/.botva_autoclicker.json`
