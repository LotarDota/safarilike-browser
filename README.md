# Авто кликер Ботва

Десктопное приложение-автокликер для браузерной онлайн-игры [Botva.ru](https://botva.ru/), написанное на Python + PyQt5 со встроенным окном Chromium-браузера.

## Возможности

- **Встроенный браузер** – окно Chromium (QtWebEngine) прямо в приложении, не нужно переключаться между окнами.
- **Автоматизация действий** – автоматическое выполнение игровых действий через JavaScript-инъекции:
  - **Основа**: Дозор, Сражалка, Бодалка, Зорро, Страшилки, Арена, Кач, Покупка, Продать, Работа, Музей, Карьера, Икарус и др.
  - **Шахта/Подъем**: Опуск за кри, Шахта, Малые/Большие приключения.
  - **Крепость**: Таверна, Катакомбы, Великий Дуб, Подземные Тонели, Академия Приключений, Арена Гладиаторов.
  - **Аватар**: Авто Бодалка, Авто Шахта, Кораблик, СборРесов, Задания, Поляны и др.
- **Авторизация** – поля ввода логина/пароля с автоматическим заполнением формы входа.
- **Лог действий** – текстовое окно статуса, где видно какие действия выполняются и их результат.
- **Выбор сервера** – выпадающий список серверов (Аватар, Призрак, Зомби).

## Установка

### Требования
- Python 3.8+
- pip

### Шаги

```bash
# Клонировать репозиторий
git clone https://github.com/LotarDota/safarilike-browser.git
cd safarilike-browser

# Установить зависимости
pip install -r requirements.txt

# Запустить
python main.py
```

## Структура проекта

```
├── main.py                        # Точка входа
├── requirements.txt               # Зависимости Python
├── app/
│   ├── __init__.py
│   ├── main_window.py             # Главное окно приложения
│   ├── browser_widget.py          # Виджет встроенного браузера
│   ├── controls/
│   │   ├── __init__.py
│   │   ├── base_panel.py          # Панель «Основа»
│   │   ├── mine_panel.py          # Панель «Подъем / Шахта»
│   │   ├── fortress_panel.py      # Панель «Крепость»
│   │   └── avatar_panel.py        # Панель «Аватар»
│   └── engine/
│       ├── __init__.py
│       ├── actions.py             # Определения игровых действий + JS
│       └── clicker.py             # Движок автокликера
```

## Использование

1. Запустите `python main.py`
2. Введите логин и пароль, нажмите **Войти**
3. Выберите нужные действия галочками
4. Поставьте галочку **Поехали** – автокликер начнёт работу
5. Снимите галочку **Поехали** чтобы остановить
